about=QGIS Environment Manager looks after the environment around QGIS. Diagnostics: version, release line (LTR or latest), Python, Qt, how QGIS was installed (on Linux: official repository, Flatpak, Snap, distribution), warnings such as an older-than-LTR version or the QGIS repository signing key that expires on 2027-08-08, and a report you can copy for support. Plugins and QGIS 4: reads each installed plugin's metadata.txt and shows what it declares for QGIS 3 and QGIS 4 (supportsQt6, minimum and maximum QGIS version), so you know what to check before moving to QGIS 4. Requirements: the GIS GEORGIA plugins that need system tools (PostgreSQL client tools and psycopg2 for PostGIS Manager, ExifTool for Photo Geotagger, SAGA and GRASS for GeoEco) are checked, and on Linux the missing ones can be installed with your package manager after you review the exact commands. The logic is shared with the standalone qgis-installer (https://github.com/kapo-Toolkits/linux-scripts).

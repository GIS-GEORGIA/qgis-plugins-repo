about=QGIS Environment Manager looks after the environment around QGIS. Diagnostics: version, release line (LTR or latest), Python, Qt, how QGIS was installed (on Linux: official repository, Flatpak, Snap, distribution), warnings such as an older-than-LTR version or the QGIS repository signing key that expires on 2027-08-08, and a report you can copy for support. Plugins and QGIS 4: reads each installed plugin's metadata.txt and shows what it declares for QGIS 3 and QGIS 4 (supportsQt6, minimum and maximum QGIS version), so you know what to check before moving to QGIS 4. Requirements: the GIS GEORGIA plugins that need system tools (PostgreSQL client tools and psycopg2 for PostGIS Manager, ExifTool for Photo Geotagger, SAGA and GRASS for GeoEco) are checked, and on Linux the missing ones can be installed with your package manager after you review the exact commands. Components: the programs and libraries around QGIS (GDAL, PROJ, GRASS, SAGA, Python libraries such as NumPy, pandas, Shapely, rasterio, database clients) with what is installed and what can be added, installed with your package manager after you review the commands - the small Linux form of the OSGeo4W chooser. QGIS versions: update the QGIS you have, or install another one next to it (Flatpak stable or lts, containers) or in its place - the program recommends the best way for your system and says why, shows every command first, and asks twice before changing the QGIS you are using right now; a zip copy of your profile can be made first. The logic is shared with the standalone qgis-installer (https://github.com/kapo-Toolkits/linux-scripts). Bilingual (ka/en). / QGIS-ის გარემოს მართვა: დიაგნოსტიკა, დანამატების თავსებადობა QGIS 4-თან და GIS GEORGIA-ს დანამატებისთვის საჭირო სისტემური ხელსაწყოები.

about=Two tools in one bilingual (ka/en) plugin. (1) Cadastre fetch — enter a cadastral code (e.g. 38.10.42.107), search the public cadastre service and load the parcel: single, batch and bulk (radius / map extent) lookup, map-click reverse lookup, auto UTM zone 37N/38N, non-personal attributes, export to SHP/DXF/CSV. All network work runs on background tasks, proxy-aware, no login. (2) Cadastral Drawing — create the official "საკადასტრო აგეგმვითი/აზომვითი ნახაზი": download SHP templates (cadastre + floor-plan) in the right CRS, add WMS/WMTS orthophoto & cadastre services, apply symbology + labels automatically by layer name, download Georgian fonts, build an A4 print layout with dynamic date/area/CRS fields, fill the Excel attachment and package the PDF + Excel + photos into one folder named after the interested party. / ქართული კადასტრი + საკადასტრო აგეგმვითი/აზომვითი ნახაზის სრული ხელსაწყო.

changelog=0.4.1 - Clearer fetch errors: when the cadastre service returns an "Access Denied"/HTML page or is down, fetch-by-code and batch now show a plain "service unavailable / try later" message (KA/EN) instead of a confusing "Invalid response". Area/radius search is unaffected. (The service itself has been unreliable lately — this is upstream, not the plugin.)
    0.4.0 - Runs on QGIS 4 (Qt6) and QGIS 3.40+ (Qt5) from the same build: scoped Qt enums, exec() instead of exec_(), QMetaType instead of QVariant field types, and Qt imported through qgis.PyQt. Minimum QGIS is now 3.40 LTR.
    0.3.4 - Neutral naming: the data-source brand is no longer shown in the UI (hints, labels, layer names) — the bulk layer is now "cadastre_parcels" and gets the cadastre outline+area style.
    0.3.3 - Fully merged the cadastre-fetch window into the Fetch-by-code tab: single, batch (list / from file, with progress + cancel) and SHP/DXF/CSV export now live inside the central window — no separate dialog opens anymore.
    0.3.2 - Area (bulk) download in the fetch tab: grab every parcel within a radius of a cadastral code, or across the current map extent, into a separate parcels layer. Runs as a background task with a live progress bar and pause / resume / cancel — the UI never freezes.
    0.3.1 - Unified into a single window: cadastre fetch-by-code (and map-click reverse) is now a tab inside the central dialog, dropping parcels straight into the nakveti layer; a 'batch / export' button still opens the full fetch dialog. One toolbar button instead of two.
    0.3.0 - Added the Cadastral Drawing toolkit (CRS 37/38 templates, WMS/WMTS services, name-based styles, Georgian fonts, A4 layout with dynamic fields, Excel attachment, packaged export) alongside the cadastre fetcher.
    0.2.0 - Cadastre code→parcel fetch: single & batch, reverse lookup, SHP/DXF/CSV export.

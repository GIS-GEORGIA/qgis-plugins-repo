about=Two tools in one bilingual (ka/en) plugin. (1) Georgian Cadastre — enter a cadastral code (e.g. 38.10.42.107), search the public maps.gov.ge / NAPR service and load the parcel: single & batch lookup, map-click reverse lookup, auto UTM zone 37N/38N, non-personal attributes, export to SHP/DXF/CSV. All network work runs on background tasks, proxy-aware, no login. (2) Cadastral Drawing — create the official "საკადასტრო აგეგმვითი/აზომვითი ნახაზი": download SHP templates (cadastre + floor-plan) in the right CRS, add NAPR WMS/WMTS orthophoto & cadastre services, apply symbology + labels automatically by layer name, download Georgian fonts, build an A4 print layout with dynamic date/area/CRS fields, fill the Excel attachment and package the PDF + Excel + photos into one folder named after the interested party. / ქართული კადასტრი + საკადასტრო აგეგმვითი/აზომვითი ნახაზის სრული ხელსაწყო.

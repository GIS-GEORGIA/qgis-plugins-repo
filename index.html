Installationინსტალაცია

Two ways to get the plugins into QGIS.პლაგინების QGIS-ში დამატების ორი გზა.

AAdd as a custom repositoryდაამატე მომხმარებლის რეპოზიტორია

  1. QGIS → Plugins → Manage and Install Plugins…QGIS → Plugins → Manage and Install Plugins…
  2. Open the Settings tab → Add…გახსენი Settings ჩანართი → Add…
  3. Name: GIS GEORGIA, URL: https://plugins.qgis.ge/plugins.xmlსახელი: GIS GEORGIA, URL: https://plugins.qgis.ge/plugins.xml
  4. Enable Show experimental plugins, then install any plugin.ჩართე Show experimental plugins და დააინსტალირე ნებისმიერი პლაგინი.

BInstall from ZIPდააინსტალირე ZIP-იდან

  1. Download a plugin's ZIP from the cards above.ჩამოტვირთე პლაგინის ZIP ზემოთ მოცემული ბარათებიდან.
  2. QGIS → Plugins → Manage and Install Plugins…QGIS → Plugins → Manage and Install Plugins…
  3. Open Install from ZIP, pick the file → Install Plugin.გახსენი Install from ZIP, აირჩიე ფაილი → Install Plugin.
  4. Enable it in the Installed tab.ჩართე Installed ჩანართში.
Tip: the repository also appears on qgis.ge. Source for every plugin lives in the GitHub repository. რჩევა: რეპოზიტორია ასევე ხელმისაწვდომია qgis.ge-ზე. თითოეული პლაგინის კოდი GitHub რეპოზიტორიაშია.

About GIS GEORGIAGIS GEORGIA-ს შესახებ

GIS GEORGIA builds open QGIS tools for processing, analysing and visualising Georgian spatial data. The plugins wrap official data sources (maps.gov.ge / NAPR) and proven engines (SAGA, GRASS, PostGIS) — adding the “last mile” that local surveyors and analysts actually need, in Georgian and English. GIS GEORGIA ქმნის ღია QGIS ხელსაწყოებს საქართველოს სივრცითი მონაცემების დასამუშავებლად, გასაანალიზებლად და ვიზუალიზაციისთვის. პლაგინები ეყრდნობა ოფიციალურ წყაროებს (maps.gov.ge / საჯარო რეესტრი) და დადასტურებულ ძრავებს (SAGA, GRASS, PostGIS) — და ამატებს „ბოლო მილს“, რომელიც ადგილობრივ სპეციალისტებს რეალურად სჭირდებათ, ქართულად და ინგლისურად.
